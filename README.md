# 短信垃圾检测 Web 应用

本项目是一个使用多种机器学习模型来检测垃圾短信的 Web 应用。它提供了一个用户友好的界面，可以预测短信是否为垃圾信息、训练新模型、管理数据集以及可视化数据洞察。

## 功能特性

- **短信垃圾检测:** 对单条短信进行分类，或通过 CSV 文件进行批量预测。
- **多种机器学习模型支持:** 使用朴素贝叶斯 (Naive Bayes)、支持向量机 (SVM)、长短期记忆网络 (LSTM) 和残差注意力长短期记忆网络 (Residual Attention LSTM) 模型进行预测。
- **模型训练与管理:**
    - 上传自定义的 CSV 格式数据集。
    - 使用可配置的参数训练新的分类模型。
    - 查看、加载和删除已训练的模型。
- **预测历史:** 查看过去的预测记录。
- **词云可视化:** 生成并显示垃圾短信和正常短信中常见术语的词云。
- **语义漂移检测:** 监控数据中潜在的概念漂移。
- **数据集管理:** 上传、查看和管理用于训练和评估的数据集。

## 技术栈

- **后端:** Python, Flask, SQLAlchemy
- **前端:** HTML, CSS, JavaScript (使用 Chart.js 进行可视化)
- **机器学习:** PyTorch, Scikit-learn, Jieba (用于中文文本分词)
- **数据库:** SQLite

## 安装与启动

### 环境要求
- Python 3.x
- pip

### 安装步骤
1. **克隆仓库:**
   ```bash
   git clone <repository_url>
   cd <repository_directory>
   ```
2. **创建虚拟环境 (推荐):**
   ```bash
   python -m venv venv
   source venv/bin/activate  # Windows 用户使用: venv\Scripts\activate
   ```
3. **安装依赖:**
   (注意: 项目中没有 `requirements.txt` 文件，以下为常见依赖，请根据实际情况调整)
   ```bash
   pip install Flask Flask-SQLAlchemy pandas numpy torch scikit-learn jieba
   ```
   如果项目有 `requirements.txt` 文件，则运行:
   ```bash
   pip install -r requirements.txt
   ```
4. **初始化数据库:**
   应用首次运行时会自动创建数据库。

### 启动应用
1. **运行 Flask 应用:**
   ```bash
   python app.py
   ```
2. 在浏览器中打开 `http://127.0.0.1:5000/` (或应用指定的其他地址和端口)。

## 使用说明

应用启动后，您可以通过浏览器访问。

- **预测单条短信:**
    1. 在首页的文本框中输入短信内容。
    2. 选择要使用的模型。
    3. （可选）调整其他参数，如发送频率、是否夜间发送。
    4. 点击“预测”按钮查看结果。

- **批量预测 (CSV 上传):**
    1. 在首页，选择“上传CSV文件进行批量预测”选项卡。
    2. 选择要使用的模型。
    3. 上传包含短信内容的 CSV 文件。系统会提示您映射包含文本内容和（可选的）真实标签的列。
    4. 点击“开始处理”按钮。处理完成后会显示结果，并将预测记录保存到历史记录中。

- **模型训练:**
    1. 导航到“模型管理”页面。
    2. 在“训练新模型”部分，选择模型类型。
    3. 选择数据源：
        - **上传新数据集:** 上传包含文本和标签的 CSV 文件。系统会提示您映射相应的列。
        - **使用现有数据集:** 从已上传的数据集列表中选择。
    4. （可选）调整训练参数，如训练轮数 (epochs)、批次大小 (batch size)、学习率等。
    5. （可选）为传统模型（如朴素贝叶斯、SVM）配置向量化参数。
    6. 点击“开始训练”按钮。训练完成后，新模型将保存在服务器上，并可用于预测。

- **模型管理:**
    1. 导航到“模型管理”页面。
    2. 您可以查看所有已保存的模型及其详细信息。
    3. 选择一个模型并点击“加载”按钮，将其设置为当前预测使用的模型。
    4. 点击“删除”按钮可以删除不再需要的模型。

- **数据集管理:**
    1. 导航到“数据集管理”页面。
    2. 您可以上传新的 CSV 数据集，并为其添加描述。
    3. 查看已上传的数据集列表及其统计信息（记录数、垃圾/正常短信数等）。
    4. 删除不再需要的数据集。

- **查看预测历史:**
    - 导航到“预测历史”页面，可以查看所有单条和批量预测的记录。
    - 可以删除单条或多条历史记录。

- **查看词云特征:**
    - 导航到“特征可视化”页面，可以查看垃圾短信和正常短信的词云图，了解高频词汇。

- **语义漂移检测:**
    - 在首页选择模型后，漂移检测会自动运行并显示结果。如果检测到显著漂移，系统可能会提示模型需要重新训练或微调。

## 项目结构

项目的主要目录和文件说明如下：

```
.
├── app.py                    # Flask 应用主文件，包含路由和主要逻辑
├── database.py               # 数据库操作相关函数 (如果独立)
├── models.py                 # SQLAlchemy 数据库模型定义
├── instance/                 # 实例文件夹，通常包含 SQLite 数据库文件
│   └── sms_spam.db           # SQLite 数据库文件
├── ml/                       # 机器学习相关模块
│   ├── model.py              # 定义机器学习模型 (如 LSTM, SVM 等)
│   ├── training.py           # 模型训练逻辑
│   ├── preprocessing.py      # 数据预处理和文本清洗
│   ├── feature_extraction.py # 特征提取逻辑
│   ├── drift.py              # 语义漂移检测逻辑
│   ├── utils.py              # ML 相关工具函数
│   └── saved_models/         # 存储已训练模型的目录
├── static/                   # 静态文件 (CSS, JavaScript, Images)
│   ├── css/
│   └── js/
├── templates/                # Flask HTML 模板文件
├── uploads/                  # 用户上传的文件 (如 CSV 数据集)
├── README.md                 # 项目说明文件
└── ...                       # 其他配置文件 (如 .replit, pyproject.toml)
```
